QAQC MOBILE APP

Versión enfocada en el Reporte Diario QA/QC.

Novedades:
- Dashboard final simplificado.
- Botón “Descargar dashboard como imagen”.
- La descarga genera un PNG.
- Mantiene formulario, guardado local, histórico, CSV y respaldo JSON.
- Total de lotes y total de muestras son editables.

Para probar:
1. Descomprime el ZIP.
2. Abre index.html en Chrome/Edge.
3. Llena el formulario.
4. Entra a Dashboard.
5. Pulsa “Descargar dashboard como imagen”.

Para instalar como PWA en celular, publica la carpeta completa en un hosting HTTPS y luego usa
“Agregar a pantalla de inicio” / “Instalar app”.
